# Tripleten web_project_around_auth
=======
proyecto react + vite 18

funciones previas al proyecto:
- editar datos de perfil
- añadir nuevas cards
- like/dislike de cards
- cambiar avatar de usuario
- popup de cards

funciones añadidas

- nuevos componentes; Login y Register
- página principal protegida '/' (si no estas logeado redirige a /signin)
- se registra nuevo usuario con un correo y contraseña
- un popup de que advierte si el registro es exitoso o erroneo
- se puede conservar la sesión guardando un token en localstorage
- implementado boton de cierre de sesión
- implementada verificación de tokens que evita saturación de localstorage
